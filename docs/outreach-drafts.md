## 4. Show HN (a technical angle, not marketing)

Title: `Show HN: Slope Tycoon, a ski resort tycoon with every asset generated by code`

> I built a 3D isometric ski resort tycoon in the browser with three.js and TypeScript. There are no asset files: terrain, models, textures, icons, sound effects, ambience and music are all procedural (the only files are two fonts). The simulation is deterministic (seeded RNG, fixed ticks), so the same seed and inputs give the same state hash, and I use that for the tests. It works offline as a PWA and saves locally; there are no accounts.
>
> It's a pre-release. The source is readable on GitHub but all rights are reserved. Most of the code was written by AI coding agents under my direction, and I'm happy to talk about what worked and what didn't.
>
> https://slopetycoon.com/ and the game itself: https://slopetycoon.com/play/
