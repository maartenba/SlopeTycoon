# Music prompts (Suno)

The prompts for the game's music tracks, kept so a track can be regenerated or extended. The shipped tracks are in `public/audio` and the situation mapping is in `src/config/audioMusic.ts` (see [audio.md](audio.md), "Music"). Nothing here is used by the game at runtime.

Every prompt ends with the shared suffix, so each one can be pasted as is:

`instrumental, no vocals, soft dynamics, warm and clean mix, no sudden loud hits, seamless loop ending`

Style note: the first prompts came out too polished. These ask for a small handmade, charming indie-game sound: few instruments, simple memorable tunes, a slightly imperfect "played in a room" feel, lo-fi warmth and tape softness, no orchestral or film-score polish. If a result is still too slick, add `lo-fi, tape saturation, slightly detuned, simple` at the start of the prompt.

## Notes

- The four apres tracks keep the same suffix on purpose, so the loop is smooth in the game even though they are dance tracks. If a generator makes them too quiet, remove "soft dynamics" from those four only.
- Length: 2-3 minutes each is plenty. The game fades tracks in and out itself.
- Shipped names (see `public/audio/README.md`) differ from these working titles: for example "Seasons of Management" is the title theme and the winter, summer and autumn tracks have two or more songs each.
