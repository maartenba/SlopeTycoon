# Slope Tycoon brand notes

Palette sampled from `public/icons/favicon.svg` (the logo) and `site/assets/site.css`.

## Name
**Slope Tycoon** (two words, both capitalised). Describe it as "a free, in-browser ski resort game". Version 0.6.5, pre-release: never call it 1.0. Licence: all rights reserved. Say "source-available", never "open source".

## Logo
A rounded square: blue-to-navy sky, a gold sun, two snowy mountains and a white piste with amber dots.
- Source: `public/icons/favicon.svg` (hand-written SVG). PNGs (`icon-192/512`, `icon-maskable-512`, `apple-touch-icon`) are generated by `scripts/site/icons.ts`. The in-game logo is procedural (`src/ui`, search "logo").
- Avatar: use `icon-512.png`. Keep the mountain and sun inside the central 80 % (safe area for round crops).

### Ko-fi and social
- Ko-fi accent colour: `#ffb84d` (amber, with navy button text). Page background: `#0b1626`.
- Site theme-color / manifest in `scripts/site/icons.ts`: `#0b1626`. The game (`index.html` and `public/manifest.webmanifest`) uses `#1d3b6e` (logo navy). Both are navy and look consistent; unifying is optional. If you do, `#1d3b6e` for the installed game (it matches the icon) and `#0b1626` for the site is a defensible split, so the recommendation is to leave it. No code was changed.

## Typography
Nunito for body, Lilita One for headings and wordmark (self-hosted in `public/fonts`). Headings sentence case.

## Tone of voice
Friendly, modest, first person ("I'm Maarten"). Light humour, used sparingly. Plain words, short sentences. No hype, no AI-isms (no "delve", "journey", "unleash", "elevate", em-dash chains, exclamation spam). No sharing/leaderboard language.

## Imagery
- Calm winter or dusk scenes: mountain, village, lift, warm window glow.
- Game screenshots with the UI hidden (Photo mode export or `npm run shot -- --view photo --photo-save 1`), quality High.
- Cool blues and navy with restrained amber. No purple or pink cast, no confetti, no text baked into covers.
- Keep the lower-left ~220x220 of the Ko-fi cover quiet (the avatar overlaps it).

## Privacy and support links
No ads, no accounts, saves stay on the device, anonymous opt-in statistics only after consent. The only support link allowed in the game or on the site is `https://ko-fi.com/slopetycoon` ("Support the game" / "Support on Ko-fi", `target=_blank rel=noopener`, never a popup or gate); the Ko-fi widget loads only on `/support/` after a click.

## Do / Don't
Do: use the palette above; show real game imagery; keep it quiet; credit nothing you did not make.
Don't: add purple or pink; add shiny sharing features; put text in covers; call it 1.0 or "open source"; add support links beyond the allowed one.
