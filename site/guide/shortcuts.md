This page is **generated from the game's own key registry**, so it is always current. In the game, press <kbd>?</kbd> or <kbd>H</kbd> for the in-game list.

Time keys (<kbd>Space</kbd>, <kbd>+</kbd>, <kbd>-</kbd>, <kbd>.</kbd>, <kbd>,</kbd>) work in every mode. The number keys never conflict with them, because they only act while a drawer or terrain tool is open.

{{gen:shortcuts}}

Keys are ignored while you type in a text field (a seed, a save name, a piste name), so typing <kbd>h</kbd> or <kbd>o</kbd> never opens Help or cycles overlays. On a touch screen see [Touch & tablets](page:touch) for the gesture equivalents.

## Mouse

| Action | Mouse |
|---|---|
| Select a building, lift, piste or guest | Click |
| Cancel the current tool | Right-click or <kbd>Esc</kbd> |
| Pan the camera | Middle or right drag |
| Rotate freely | <kbd>Alt</kbd> + drag |
| Zoom | Wheel |
| Place several buildings | <kbd>Shift</kbd> + click |
